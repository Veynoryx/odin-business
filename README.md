# Aurora Coffee Website

A coffee shop website I built to practice frontend development and improve my skills with layout and styling.

## Preview

This project is a café-style landing page with a warm coffee theme.  
It includes a hero section, specialties cards, a quote section, and a call-to-action.

## Built With

- HTML
- CSS
- Flexbox
- Grid

## What I made

- A homepage for a coffee brand called **Aurora Coffee**
- A navbar with links like Menu, About, and Contact
- A hero section with text and an image
- An **Our Specialties** section with cards
- A quote section
- A call-to-action section at the bottom
- A consistent color theme based on coffee tones

## What I focused on

With this project I mainly focused on:

- building a clean layout
- improving my CSS
- working with Flexbox and Grid
- making the design feel like a real website instead of just a practice page

## Things I ran into

### 1. Spacing
Getting spacing right was harder than expected.  
Sometimes sections looked too empty, and other times too crowded.  
I had to adjust margins and padding a lot to get a better balance.

### 2. Layout decisions
Deciding how to structure sections (like the hero and the specialties cards) took some trial and error.  
I changed positioning and alignment multiple times before settling on the current layout.

### 3. Making it look real
It’s easy to build something functional, but harder to make it actually look like a real brand.  
I spent time trying to make the design feel consistent and on-theme.

### 4. Class naming
I used simple class names like `card`, `text`, and `section`.  
It works for now, but I can see how this might become messy in bigger projects.

## What I learned

From this project I learned more about:

- structuring a landing page
- using Flexbox and Grid
- improving layout and spacing
- thinking more about design, not just code

## What I would improve

If I continue working on this project, I would:

- improve the overall polish of the design
- make sections stand out more (especially the hero)
- refine spacing and alignment further
- expand it into multiple pages (Menu, About, Contact)
